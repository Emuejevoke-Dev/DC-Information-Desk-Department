# Dominion City Asaba — Information Desk Management System

A full-featured church departmental operations, hospitality, and management portal built for **Dominion City Asaba Central**.

---

## 🌟 Key Features

### 1. Role-Based Access Control & Dedicated Workspaces
* **👑 Head of Department (HOD) Oversight:** Supervisory dashboard covering department health, attendance trends, roster schedules, financial status, and reports.
* **💼 Financial Officer Workspace:** Income, expense tracking, tithes/welfare dues, and digital financial receipting.
* **📋 Department Secretary Workspace:** Service attendance registers, documentation archives, meeting minutes, and member onboarding.
* **📖 Book Stand Desk:** Inventory control, literature sales, debt tracking, and stock management.
* **👗 Uniform & Protocol Leader:** Sunday outfit planner, color guides, and dress code rosters.
* **👥 Active Department Members:** Self-service profile, duty roster schedule, prayer meetings, and announcements.

### 2. Smart Automation & Security
* **Password Memory & Credential Retention:** Automatic credential memory stored locally on device.
* **Self-Service Password Recovery:** Instant email confirmation and secure password generation with automatic page reset.
* **Audit Logging:** Full departmental action and security event auditing.
* **Cell & Satellite Church Directory:** Searchable directory of Asaba cell fellowships and satellite branches with contact info.
* **Lost & Found Custodial Register:** Item intake, tracking, photo verification, and return audit slips.

---

## 🚀 Tech Stack

* **Frontend:** React 19, TypeScript, Vite
* **Styling:** Tailwind CSS, Glassmorphism design system, Lucide React Icons
* **Data Persistence:** LocalStorage & Cloud synchronization adapters

---

## 🛠️ Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18 or newer)
* npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Build optimized production bundle
npm run build
```
